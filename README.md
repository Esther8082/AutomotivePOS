# AutomotivePOS

A web-based automotive spare-parts management application built with React, TypeScript, Vite, Node.js, Express and PostgreSQL.

## Features
- Automotive spare-parts search
- Parts catalogue
- Add-parts functionality
- Vehicle API
- PostgreSQL database integration

## Requirements
- Node.js and npm
- PostgreSQL

## Installation
1. Clone this repository.
2. Run npm install.
3. Create a local .env file using .env.example as a template.
4. Configure your PostgreSQL connection details.

## Run the application
- Frontend: npm run dev
- Backend: npm run server

## Production build
Run npm run build.
